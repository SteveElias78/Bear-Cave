## My creative point of view

In my own words from my sketches:

> "merging luxury fashion aesthetics with geometric code ... something that feels more gallery installation than typical student project"

What shows up again and again in this folder:

* Editorial fashion photography as the north star (Vogue Japan, studio light, motion in fabric)
* One product, many worlds: each spec brand gets its own complete visual language (desert strata, Swiss lab grid, nautical chart, candlelit stone, island beauty)
* Luxury materials up close: amber glass, gold foil, woven leather, silk
* Sacred geometry, golden ratio motion, mandalas, prisms and murmurations in code
* Code layered on photography: generative effects driven by a model's motion
* Hawaiʻi as a recurring place: vintage postcards, botanicals, the island chain
* Restraint plus one bold move (a single red gown, a single gold accent)

## How I work

* AI-native: I direct, AI builds, I review. Git history is the record of decisions.
* Spec and plan before build. Small commits with clear messages.
* Vanilla HTML / CSS / JavaScript for the web, Processing and p5.js for generative work
* ComfyUI for image pipelines (IP-Adapter for style, ControlNet for pose); Claude Code to automate the grunt work
* Maya and Unreal Engine for 3D product visualization; Premiere for edits
